## 🛠️ Development

### Prerequisites

- C++ compiler with C++17 support
- CMake 3.10 or higher
- Doxygen (for documentation generation)

### Building

1. Clone the repository:
```bash
git https://github.com/impelixx/SIGMAinterpretator.git
cd SIGMAinterpretator
```

2. Build the project:
```bash
mkdir build
cd build
cmake ..
make
```

### Running Tests

```bash
cd build
ctest
```
